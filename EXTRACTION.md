# Music extraction from Anchor

Every file here is copied verbatim from `~/Anchor` on 2026-09-04. Nothing has
been edited, so each still carries its GPL-3.0 header crediting Atoll and
boring.notch. **The extraction inherits GPL-3.0** — see Licensing at the bottom.

Nothing here has been compiled. The dependency analysis below is from symbol
resolution across the tree, not from a build.

## What each group is

### `Sources/Core/` — the playback model
| File | What |
|---|---|
| `MusicManager.swift` (1,895) | The centre of everything. Publishes 27 properties: title, artist, album, artwork, `elapsedTime`, `songDuration`, `isPlaying`, shuffle/repeat, `avgColor`, explicitness, lyrics. Owns controller selection, artwork colour extraction, iTunes/Spotify explicitness lookup, and the lyric-sync task. |
| `PlaybackState.swift` | The struct every controller emits. |
| `MusicControlButton.swift` | The configurable transport-button slot model. |
| `MediaChecker.swift` | Which media app is frontmost/playing. |

### `Sources/MediaControllers/` — the sources
`MediaControllerProtocol` plus five implementations: Apple Music and Spotify
(AppleScript), Amazon Music, YouTube Music (WebSocket, with a 2 s polling
fallback), and `NowPlayingController` (private MediaRemote — covers everything
else). `SpotifyAuthManager` does the SP_DC-cookie token dance.

**All five are event-driven** except the YouTube Music fallback. Nothing polls
for playback state.

### `Sources/Vinyl/` — the turntable
| File | What |
|---|---|
| `VinylRecordView.swift` (237) | The record itself. **CALayer, not SwiftUI** — a `CABasicAnimation` handed to the render server once, removed on pause rather than left at zero speed. Album art is masked to a circle via `CGImage` + `CAShapeLayer`, because `CALayer.contents` from an `NSImage` honours neither `contentsGravity` nor corner radius. |
| `VinylWidgetView.swift` (416) | Chrome around it — stylus arm, progress (bar/ring/none), title, album-colour tint, background opacity. Also defines `VinylProgressStyle`. |
| `VinylWidgetWindowManager.swift` (296) | Borderless `NSPanel`, four window levels (desktop→above-all), size and orientation, position persistence, torn down while the display sleeps. Defines `VinylWidgetSize`, `VinylOrientation`, `VinylWindowLevel`. |

This is the closest thing to the pod you want, and it is the cleanest part of
the extraction — its only outside reference is a comment.

### `Sources/Visualizer/` — spectrum and waveform
`AudioTap` (450) is a CoreAudio process tap, **reference-counted** via
`acquire()`/`release()` so it is built on 0→1 consumers and torn down on 1→0.
`RealTimeAudioSpectrum` + the C++ `AudioProcessor` do the FFT.
`MusicVisualizer` is the bar visualiser; `RealTimeWaveformScrubberView` is the
hover-scrub waveform.

Getting this wrong was worth 12x the app's idle CPU — do not start the tap at
launch.

### `Sources/Lyrics/`
`SyncedLyricsList` (scrolling, tap-to-seek), `NotchLyricsView`,
`LyricsTranslator`. Fetching and `LyricLine` live in `MusicManager`.
The sync loop sleeps until the next line rather than polling.

### `Sources/Artwork/`
`AnimatedArtworkManager` (Apple Music animated covers), `ImageService`,
`FullScreenArtworkWindowManager` (1,807 — full-screen canvas; **lock-screen
coupled**, see below).

### `Sources/Overlay/` — the on-screen players
`MusicControlOverlay`, `MinimalisticMusicPlayerView`, `MusicSupplementViews`,
`MarqueeTextView`, `LiveStreamProgressIndicator` (live streams report a NaN
duration — that guard matters), `LottieAnimationView`, and the per-display
control window (`MusicControlWindowManager.manager(for:)` returns one instance
per screen, keyed by `NSScreen.localizedName`).

**This is the most notch-coupled group.** See the table below.

### `Sources/Routing/`
`AudioRouteManager` (output device enumeration/switching),
`AppleMusicAirPlayManager`, `BluetoothAudioManager`.

`BluetoothAudioManager` still polls `IOBluetoothDevice.pairedDevices()` every
15 s idle / 3 s connected. It is the largest non-idle main-thread leaf in the
whole app. If you keep it, that is the first thing to rewrite — but note
IOBluetooth blocks on a main-queue semaphore in `init` and deadlocked Anchor
once at launch.

### `Sources/Support/`
`MusicTypes.swift` and `MusicDefaults.swift` are **generated by this
extraction**, not copied: the 4 music enums and the **73 `Defaults` keys** the
extracted files actually reference, lifted out of Anchor's 412-key
`Constants.swift`. Plus `AppleScriptHelper`, `AppleScriptError`,
`AnchorAnimations`, `SystemActivityGate`, and `SettingsMedia.swift` as a
reference for what is configurable.

## What does not resolve

Everything else compiles against itself. These are the files with references to
Anchor types left behind:

| File | Unresolved | Verdict |
|---|---|---|
| `Core/MusicManager.swift` | `AnchorViewCoordinator` | **2 lines**, both `toggleSneakPeek`/`toggleExpandingView` at :1199-1201. Delete them or point at your own UI. `AnchorAnimations` and `ClipboardItem` are resolved/comment-only. |
| `Vinyl/VinylWidgetWindowManager.swift` | `LauncherPanel` | Comment only. **Clean.** |
| `Overlay/MusicControlWindowController.swift`<br>`Overlay/MusicControlWindowManager.swift` | `AnchorViewModel`, `ContentView`, `LockScreenManager`, `ScreenCaptureVisibilityManager` | Structural — these position a window relative to the notch. Keep as a reference for the per-display logic, not as code to drop in. |
| `Overlay/MinimalisticMusicPlayerView.swift` | 13 types (sliders, popovers, timer, brightness/volume controllers) | It is a *notch* player that also draws non-music things. Harvest the layout, not the file. |
| `Overlay/MusicSupplementViews.swift` | `TimerManager`, `FocusModeType`, reminders | Same. |
| `Artwork/FullScreenArtworkWindowManager.swift` | `LockScreenManager`, `LockScreenPanelManager`, `ScreenCaptureVisibilityManager` | Built for the lock screen. 1,807 lines; the artwork logic is worth reading, the window management is not portable. |
| `Routing/BluetoothAudioManager.swift` | `AppDelegate`, `HUD`, `HUDSuppressionCoordinator` | Wants Anchor's HUD to announce device changes. |
| `Support/SettingsMedia.swift` | 16 types | Reference only — it is Anchor's settings pane. |

**Clean out of the box: `MediaControllers/`, `Lyrics/`, `Visualizer/`,
`Vinyl/`.** That is the whole spine of a vinyl pod.

## Suggested minimum for a vinyl pod

```
Core/MusicManager.swift  (drop the 2 coordinator lines)
Core/PlaybackState.swift
Core/MediaChecker.swift
MediaControllers/*        (or just NowPlayingController — it covers every app)
Vinyl/*
Support/MusicTypes.swift, MusicDefaults.swift, AppleScriptHelper.swift, AppleScriptError.swift
```

Add `Visualizer/` only if you want the spectrum, and keep its reference
counting intact.
